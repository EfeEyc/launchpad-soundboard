# Setup Guide

## Requirements
- **VB-Audio Virtual Cable** (or equivalent virtual audio device) installed.
- Novation Launchpad Mini MK2. (other Launchpad models not tested)

## Audio & Discord Setup
1. Launch **Launchpad Soundboard**.
2. **What YOU Hear (Headphones)**: Select your primary headphones/speakers.
3. **What DISCORD Hears**: Select `CABLE Input (VB-Audio Virtual Cable)`.
4. **Physical Microphone**: Select your actual microphone and keep **Mic Passthrough ON**.
5. In **Discord** (Settings -> Voice & Video):
   - Set **Input Device** to `CABLE Output (VB-Audio Virtual Cable)`.
